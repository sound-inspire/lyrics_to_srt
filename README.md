# lyrics_to_srt

日本語の歌詞テキストと音源（WAV）から、歌詞どおりの字幕ファイル（SRT）を作ります。

Whisper の聞き取り結果は字幕本文にしません。渡した歌詞の1行が、字幕1枚になります。`[Intro]` や `[Chorus]` などのセクション行は字幕に出ません。

サンプル歌詞は、9匁「重さの置き場所」です。音源は同梱していません。

## 必要なもの

- Python 3.10 以降
- [ffmpeg](https://ffmpeg.org/)（`ffmpeg` がコマンドとして使えること）
- 下記の Python パッケージ

```bash
pip install -r requirements.txt
```

初回は Whisper の `medium` モデルを取得します。処理は CPU で動きます。ミックス音源だけを渡した場合は、demucs でボーカルを分離するため、曲の長さに応じて数分余計にかかります。

## 使い方

歌詞テキストと WAV を、順不同で渡します。拡張子とファイル名で役割を判別します。

| ファイル | 役割 |
| --- | --- |
| `歌詞.txt` | 必須。空行と `[...]` の行は無視し、残った1行が字幕1枚 |
| `曲 (Vocals).wav` | 任意。ファイル名に `vocal` を含む WAV。ボーカルステムとして使い、分離を省略する |
| `曲.wav` | ミックス音源。ステムが無いときは分離に使う。ステムと一緒のときは拍の位置の測定に使う |
| `出力.srt` | 任意。省略すると WAV と同じ場所に `曲.srt` を書く |

Windows では、歌詞テキストと WAV を `lyrics_to_srt.bat` にまとめてドラッグ＆ドロップできます。

```bash
python lyrics_to_srt.py sample_重さの置き場所_lyrics.txt "曲 (Vocals).wav" "曲.wav"
```

ステムが無い場合:

```bash
python lyrics_to_srt.py 歌詞.txt 曲.wav
```

出力ファイル名を指定する場合:

```bash
python lyrics_to_srt.py 歌詞.txt "曲 (Vocals).wav" 出力.srt
```

省略時の名前からは、末尾の `(Vocals)` や `123bpm` を除きます。

## テンポ

WAV のファイル名に `123bpm` のように書いておくと、そのテンポを使います。書いてあっても音声で確認し、食い違う場合は警告して実測値を使います。

書いていなくても、ミックス音源があれば拍を実測します。ステムだけで、ファイル名にもテンポが無い場合は、拍への吸着をしません。

拍の位置へ字幕の頭を吸着する機能は、初期状態ではオフです。行頭は拍より前に入ることが多く、吸着するとかえってずれるためです。

## 処理の流れ

1. ボーカルステムが無ければ、demucs でボーカルだけを分離する（一時ファイルは読み込み後に消す）
2. Whisper で聞き取り、1秒以上の空白を間奏とみなす
3. 間奏で区切り、ブロックごとに歌詞を強制アライメントする
4. ブロック先頭行の開始を、ボーカルの無音明け（無ければ息継ぎの谷）に合わせる
5. 全行を 0.1 秒だけ前に出す（読む時間の分、声より少し先に字幕を出す）

## 歌詞ファイル

UTF-8 です。次の行は字幕にしません。

- 空行
- 行全体が `[Intro]` のような `[...]` の行

残った行が、上から順に字幕になります。文字の書き換えはしません。

## サンプル

`sample_重さの置き場所_lyrics.txt` は、9匁「重さの置き場所」の歌詞です。同じ形式で、自分の曲の歌詞テキストを渡せます。
